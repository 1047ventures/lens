# Changing Lens yourself (one-time setup)

You can ask Claude Code to change Lens for you. It sends the change to Sean, he checks it,
and Lens updates itself on your Mac. This setup takes about 5 minutes, once.

## 1. Get the Lens code (one time)
In Claude Code, start a new session in any folder and paste this:

> Set me up to work on Lens. Make sure the GitHub command line tool is installed and I'm logged
> in to GitHub as EmmaPion-Berlin (walk me through the login). Then download
> github.com/1047ventures/lens into my Documents folder.

Follow what it asks. When it opens a GitHub page in your browser, approve it there.

## 2. Each time you want a change
1. In Claude Code, open a session in the **Documents/lens** folder.
2. Say what you want in plain words, like "add a field for second shooter on projects".
3. It makes the change and sends it to Sean. That's it.

## Good to know
- Nothing reaches your app until Sean publishes it. You can't break your Lens by trying things.
- Your photos, clients and money stay on your Mac. They're never part of the code.
- For quick questions about your business, Ask Lens inside the app is still the place.
